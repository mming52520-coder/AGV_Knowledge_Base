# 硬件系统总览

## 感知与状态

| 硬件 | 主要作用 | 软件对应 |
|---|---|---|
| [[MS16A磁传感器]] | 磁线位置与磁钉事件 | `magnetic_controlled_motor` |
| [[DYP-A21超声传感器]] | 多方向距离与障碍状态 | `ultrasonic_controlled_motor` |
| [[编码器与里程反馈]] | 角度、速度与里程 | `encoder`、`odometer` |
| IMU | 姿态与航向 | `wheeltec_base`、`trajectory_recorder` |
| [[H56BR电池表]] | 电压、电流、SOC | `h56br_driver` |

## 执行与底盘

| 硬件 | 主要作用 | 软件对应 |
|---|---|---|
| [[STM32底盘控制器]] | 接收 Twist 并反馈底盘状态 | `wheeltec_base` |
| [[OID与YZ_AIM电机控制器]] | 驱动与转向闭环控制 | `chassis_controller`、转向组件 |
| [[华控IO与模拟量模块]] | 模拟量、制动和离散 IO | `analog_controlled_motor`、`chassis_controller`、`relay` |

## 通信

[[串口CAN与RS485总线|串口、CAN 和 RS485]] 是主要设备总线。详细波特率、站号与寄存器值必须从已确认的配置和手册读取；本总览不保存可能敏感的现场连接信息。
