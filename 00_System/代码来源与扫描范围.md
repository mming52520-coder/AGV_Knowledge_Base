- 二号车：`main`，基线提交 `59a915f1b32b9d304ea0db5f3b962e21406030ae`，扫描时存在未提交修改。

因此本批知识以“当前文件快照”为准，不能只用基线提交还原。

## 默认纳入

- 三号车当前 `src`。
- 三号车 `docs`、工作记忆以及 `D:\推料车项目\2.工作记忆` 中的架构与调试文档。
- 一号车、二号车当前 `src` 的包级差异。
- 硬件手册的名称、型号和经源码验证的接口摘要。

## 默认排除

- `4.历史代码留存`。
- `build`、`devel`、`install`、`log`、旧路径缓存和 `.git`。
- `*.bag`、压缩包、虚拟机、安装程序、编译产物。
- 轨迹 YAML 原始数据只汇总为数据集，不逐文件建节点。
- `6.Gitee推送管理` 与所有可能包含凭据的内容。
- MQTT、云服务器、摄像头配置中的实际账号、地址、令牌和密码。

## 维护规则

每次重新扫描必须更新日期、主源 Git 状态和快照哈希。哈希变化只表示源文件集合发生变化，不自动代表功能已验证。
