# 导航决策与安全层

负责“怎么走”和“能不能走”。核心模块为 `magnetic_controlled_motor` 和 `ultrasonic_controlled_motor`。

## 职责

- 读取磁线位置和磁钉事件，产生循线建议。
- 读取前后左右超声数据，执行限速、停车和避障约束。
- 为轨迹跟踪与遥控提供安全边界。
