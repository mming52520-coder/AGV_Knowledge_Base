# 底盘与执行抽象层

负责把上层控制意图转换成具体硬件动作，并隔离底盘协议差异。

## 模块

`wheeltec_base`、`chassis_controller`、`analog_controlled_motor`、`relay`，以及转向电机控制节点。

## 两条控制链

- 兼容链：`/motor_speed` + `/motor_command` + `/motor_brake` → `cmd_vel_adapter` → `/cmd_vel` → STM32 底盘。
- 新链：`/chassis/cmd` → `chassis_bridge` → 华控模拟量或 OID RS485 控制器。
