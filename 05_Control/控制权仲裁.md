## 执行路径

- 旧底盘链：控制源 → 旧控制 Topic → [[../03_ROS/Nodes/cmd_vel_adapter]] → [[../03_ROS/Interfaces/cmd-vel]] → [[../03_ROS/Nodes/wheeltec_robot_node]]
- 新底盘链：控制源 → [[../03_ROS/Interfaces/chassis-cmd]] → [[../03_ROS/Nodes/chassis_bridge]] → 真实底盘后端

## 当前不能确认的事项

静态源码证明“能够发布”，但没有证明以下条件在所有 Launch 组合中成立：

1. 同一时刻只有一个主控制源。
2. 超声安全约束具有明确且一致的优先级。
3. 遥控接管、任务暂停和急停能够可靠撤销旧命令。
4. 旧链和新链不会同时驱动同一硬件。
5. 节点退出或通信超时后底盘进入安全状态。

## 验证建议

- 在三号车运行时记录 `rosnode list`、`rostopic info` 和控制 Topic 发布者。
- 针对轨迹、遥控、磁循线、超声停车和节点异常分别执行切换测试。
- 将运行时结论写入测试记录后，再把本节点状态改为 `active`。
