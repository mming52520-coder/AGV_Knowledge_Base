# AGV Knowledge Base
机器人研发知识库，采用 **Windows Obsidian 主编辑 + GitHub Public 仓库同步 + Ubuntu Codex/ROS 工程协作** 的工作方式。

当前仓库按负责人要求保持公开。仓库尚未添加开源许可证；公开可读不表示所有资料均可再许可。提交前须检查来源敏感级别、本地路径和凭据，尤其不能把原始受限资料加入仓库。

## 环境分工

- Windows：Obsidian 笔记、方案设计、会议记录、测试归档与 `.obsidian` 配置维护。
- Ubuntu：Codex 读取方案、分析 ROS 工程、补充接口与测试结果。
- Git：版本历史和双端同步；不替代备份，也不允许两端同时编辑同一篇笔记。
